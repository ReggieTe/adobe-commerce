# A.4 Code Review Checklist

> Part of the *Enterprise Adobe DXP Development Handbook* v1.0 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the README at the root of this folder for the section map.

- [ ] Meets acceptance criteria and design
- [ ] Uses supported extension points, no core overrides
- [ ] Readable, consistent with standards
- [ ] Error handling, timeouts and retries appropriate
- [ ] Input validated, output encoded, access checks present
- [ ] No secrets or personal data in code or logs
- [ ] Tests meaningful and passing
- [ ] Performance and caching impact considered
- [ ] Observability added
- [ ] Docs and configuration updated
