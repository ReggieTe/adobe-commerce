# 13. Definition of Success and Closing Principle

> Part of the *Enterprise Adobe DXP Development Handbook* v1.0 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the README at the root of this folder for the section map.

## 13.1 Definition of Success
**Business:** Delivered features meet acceptance criteria and agreed outcomes.
**Technical:** Solution is upgrade-safe, tested, secure, performant and observable.
**Operational:** A named owner can release, maintain and extend it.
**Engagement:** Deliverables accepted, documentation complete, knowledge transferred, debt and risks recorded.

## 13.2 Closing Principle

### Build Standard. Ship Safely. Hand Over Fully.

The consultant's responsibility is not only working software, but software the client can understand, change and operate.
