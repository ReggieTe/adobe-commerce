# 3. Development Lifecycle Overview

> Part of the *Enterprise Adobe DXP Development Handbook* v1.0 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the README at the root of this folder for the section map.

| Phase | Name | Primary outcome | Gate |
|---|---|---|---|
| 1 | Requirements and Technical Discovery | Clear, prioritised, testable requirements and constraints | E1 |
| 2 | Architecture and Technical Design | Approved solution and component design | E2 |
| 3 | Foundations: Environments, Repositories and Pipelines | Working delivery platform and standards | E3 |
| 4 | Implementation | Working, reviewed, tested increments | E4 |
| 5 | Quality Engineering | Evidence that the solution is fit to release | E5 |
| 6 | Release and Deployment | Controlled production release | E6 |
| 7 | Stabilisation and Developer Handover | Stable release and a client team able to continue | E7 |

Phases iterate: Phases 4–6 repeat per release or sprint increment, while gates E1–E3 are normally passed once per programme or major scope change. Reference diagram: Appendix C.1.
