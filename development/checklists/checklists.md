# Checklists

> Part of the *Enterprise Adobe DXP Development Handbook* v1.0 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the README at the root of this folder for the section map.

## B.1 Requirements readiness (E1)
- [ ] Backlog prioritised with acceptance criteria
- [ ] NFRs measurable
- [ ] Debt and current state reviewed
- [ ] Build/configure decisions recorded

## B.2 Design readiness (E2)
- [ ] All designs approved
- [ ] Supported extension points listed; exceptions have ADRs
- [ ] Product facts re-verified with dates
- [ ] Threat model reviewed

## B.3 Foundations (E3)
- [ ] Sample change deployed end to end through the pipeline
- [ ] Standards, definition of done and review rules agreed
- [ ] Secrets in a vault, none in source
- [ ] Lower-environment data policy applied

## B.4 Release candidate (E4)
- [ ] Quality gates green
- [ ] Review complete and findings dispositioned
- [ ] Docs and configuration current

## B.5 Quality evidence (E5)
- [ ] Regression, integration, performance, security, accessibility results accepted
- [ ] UAT signed
- [ ] Operability review done

## B.6 Release (E6)
- [ ] Change approved
- [ ] Rollback or forward-fix ready
- [ ] Production verification passed
- [ ] Operational owner accepted the release

## B.7 Handover (E7)
**Entry condition**
- [ ] Named maintaining owner accepted in writing (or fallback executed)

**Handover**
- [ ] Repositories, pipelines, environments and accounts owned by the client
- [ ] Documentation and ADRs delivered
- [ ] Knowledge transfer complete with supervised exercises
- [ ] Debt register and roadmap delivered
- [ ] Credentials transferred securely
- [ ] Handover acceptance signed
