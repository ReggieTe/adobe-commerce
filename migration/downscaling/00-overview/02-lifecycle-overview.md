# 5. Lifecycle Overview

> Part of the *Adobe DXP Downscale Playbook* v1.0 (Review Draft). Section numbers (§) refer to the playbook's original numbering; see the root [README](../README.md) for the section map.

| Phase | Name | Primary outcome | Gate |
|---|---|---|---|
| 1 | Exit Discovery and Entitlement Review | Know what exists, what can be exported, and the contract clock | D1 |
| 2 | Target Selection and Strategy | Choose the target, dispositions, data and sequencing strategy | D2 |
| 3 | Design | Target architecture, data mapping, SEO and redirect design | D3 |
| 4 | Build and Configuration | Target platform, integrations and migration tooling ready | D4 |
| 5 | Extraction and Data Migration | Export from Adobe, load, rehearse, reconcile, archive | D5 |
| 6 | Testing and Cutover | Validate, switch traffic, keep Adobe as fallback | D6 |
| 7 | Hypercare, Handover and Adobe Decommissioning | Stabilise, hand over, terminate Adobe cleanly | D7 |

Reference diagram: Appendix C.1. Phases may overlap, but gates need documented evidence.
