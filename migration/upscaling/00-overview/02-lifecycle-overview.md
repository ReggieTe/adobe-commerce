# 3. Migration Lifecycle Overview

> Part of the *Enterprise Adobe DXP Migration Handbook* v1.1 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the root [README](../README.md) for the section map.

| Phase | Name | Primary outcome | Gate |
|---|---|---|---|
| 1 | Discovery | Understand the current business and technology landscape | G1 |
| 2 | Assessment and Strategy | Determine the migration approach and business case | G2 |
| 3 | Design | Define the target architecture and implementation design | G3 |
| 4 | Build and Development | Implement the target solution and migration tooling | G4 |
| 5 | Content and Data Migration | Execute rehearsals, reconcile, approve migration readiness | G5 |
| 6 | Testing and Cutover | Validate readiness and transition to production | G6 |
| 7 | Hypercare, Support and Handover | Stabilise and transfer ownership | G7 |

Phases may overlap, but each requires its gate and documented outputs. Reference diagram: Appendix C.1.
