# 13. Project Deliverables Summary

> Part of the *Enterprise Adobe DXP Migration Handbook* v1.1 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the root [README](../README.md) for the section map.

| Phase | Primary deliverables |
|---|---|
| 1 Discovery | Current-state discovery report, platform inventory, infrastructure inventory, integration register, data inventory |
| 2 Assessment and Strategy | Gap analysis, Adobe product mapping, hosting strategy and decision record, migration strategy, roadmap, risk and cost assessment, intended operating model |
| 3 Design | Solution, application, infrastructure, integration, data, security, observability and DR designs, operating model |
| 4 Build | Configured Adobe environment, custom applications, middleware, integrations, migration utilities, monitoring, technical documentation |
| 5 Migration | Scope register, mappings, execution plan, rehearsal report, reconciliation and acceptance |
| 6 Testing and Cutover | Test strategy, reports, UAT approval, operational readiness assessment, cutover and rollback runbooks, go-live acceptance, operational owner appointment |
| 7 Hypercare and Handover | Stabilisation report, support model, documentation repository, knowledge-transfer records, operational handover and closure |
