# Checklists

> Part of the *Enterprise Adobe DXP Support and Operations Handbook* v1.0 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the README at the root of this folder for the section map.

## B.1 Discovery (S1)
- [ ] Estate, vendors and contracts inventoried
- [ ] Health assessment risks owned
- [ ] Skills gaps identified
- [ ] Service owner named

## B.2 Service design (S2)
- [ ] Catalogue, SLA and OLAs agreed
- [ ] Processes and tooling approved
- [ ] Alerts have owners and runbooks
- [ ] Backup, restore and DR operations agreed
- [ ] Adobe facts re-verified with dates

## B.3 Transition-in (S3)
- [ ] Access with least privilege and MFA
- [ ] Runbooks tested
- [ ] Training and shadow period complete
- [ ] Paging and escalation tested
- [ ] Vendor tickets can be raised with the right evidence
- [ ] Owner and provider accepted in writing

## B.4 Routine operations
**Daily**
- [ ] Critical journey smoke tests pass
- [ ] Alerts reviewed and actioned
- [ ] Jobs, cron, queues, indexing, replication and ingestion healthy
- [ ] Backups succeeded

**Weekly**
- [ ] Incident and problem review
- [ ] Alert noise review
- [ ] Certificate and credential expiry check (look-ahead)
- [ ] Open vendor tickets chased

**Monthly**
- [ ] Access review
- [ ] Patch and vulnerability status
- [ ] KPI report prepared and reviewed
- [ ] Capacity and cost review
- [ ] Runbook review for recent incidents

**Quarterly**
- [ ] Restore test performed and recorded
- [ ] DR exercise or tabletop
- [ ] Lifecycle calendar review
- [ ] Service review with the business

## B.5 Major incident
- [ ] Declared with severity and start time
- [ ] Incident commander and communications lead assigned
- [ ] Bridge open; timeline recording started
- [ ] Vendors engaged in parallel
- [ ] Stakeholder updates at agreed interval
- [ ] Service restored and verified
- [ ] Post-incident review scheduled

## B.6 Transition-out and handback (S7)
**Entry condition**
- [ ] Named service owner and provider accepted in writing (or fallback executed)

**Handback**
- [ ] Runbook library and knowledge base handed over
- [ ] Ticket history, registers and monitoring catalogue handed over
- [ ] Access and credential inventory reconciled; secrets rotated
- [ ] Shadow and reverse-shadow completed
- [ ] Open incidents, problems and changes assigned
- [ ] Vendor register updated
- [ ] Written acceptance signed
