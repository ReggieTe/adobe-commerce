# PHASE 3: TRANSITION-IN

> Part of the *Enterprise Adobe DXP Support and Operations Handbook* v1.0 (Review Draft). Section numbers (§) refer to the handbook's original numbering; see the README at the root of this folder for the section map.

## 6. Phase 3 – Transition-In

### 6.1 Objective
Move from design to a team that can run the service safely.

### 6.2 Access and Tooling Setup
Provision accounts and roles for the support team (least privilege, MFA), vendor portal access, monitoring and logging access, ticketing, paging and runbook repository. Credentials are held in the client's vault.

### 6.3 Knowledge Capture and Runbooks
Create or validate runbooks for: restart and recovery steps, cache and CDN purge, job and cron checks, deployment and rollback, content publishing issues, indexing issues, integration failure handling, certificate renewal, access requests, backup restore, DR failover. Each runbook has an owner and a last-tested date (template A.3).

**Deliverable:** Runbook Library.

### 6.4 Training
Product administration, architecture walkthrough, incident and major incident drills, runbook walkthroughs, vendor escalation practice, tooling. Record attendance and practical results.

**Deliverable:** Training Record.

### 6.5 Shadow and Reverse-Shadow Period
Support team observes the outgoing team, then performs tasks under supervision. Track incidents handled, accuracy, gaps and confidence.

### 6.6 Readiness Testing
Test alerts reach the right people, escalation works, severity drills run, backups restore, vendor tickets can be raised with the right evidence, and on-call paging works.

### 6.7 Go-Live of the Service
Formal start date, communication to users, support contact details published, hypercare arrangements agreed.

### 6.8 Phase 3 Exit Criteria (Gate S3)
- Access and tooling in place.
- Runbooks and knowledge base reviewed and tested.
- Training complete and shadow period successful.
- Readiness tests passed.
- Start date communicated.
- **Named service owner and support provider accepted in writing.**

**Final Deliverable:** Transition-In Completion Report.
